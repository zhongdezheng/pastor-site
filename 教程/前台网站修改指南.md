# 🛍️ pastor-site 前台网站修改指南

> 更新日期：2026-08-06

---

## 架构总览

```
用户浏览器
    ↓ 访问
pastorjeffnchina.com (Cloudflare Pages 部署的静态网站)
    ↓ 页面加载后 JS fetch
admin.pastorjeffnchina.com/api/xxx (管理后台 API，返回 JSON 数据)
    ↓ 读取
SQLite 数据库（你在管理后台编辑的所有内容）
```

**核心逻辑**：前台页面打开 → JS 发请求到后台 API → 拿到数据 → 渲染到页面上。

## 二、改了内容后怎么让前台更新

### 方式 1：网页触发（推荐）
在浏览器打开（登录管理后台后）：
```
https://admin.pastorjeffnchina.com/api/rebuild-frontend
```
看到 `{"ok":true}` 就触发了，等 2-3 分钟后刷新前台即可。

### 方式 2：命令行
```bash
bash ~/Desktop/pastor-site/deploy.sh
```

## 四、常用修改

### 4.1 改 WhatsApp 号码

搜索 `wa.me/85297094785`，替换为你自己的号码（去掉 + 号，如 `8613800138000`）：
- `src/components/ProductShowcase.astro`（第 1 处）
- `src/components/ProductCarousel.astro`（第 1 处）
- `src/pages/en/courses/index.astro`（第 1 处）
- `src/pages/zh/courses/index.astro`（第 1 处）
- `src/pages/en/cart/index.astro`（第 1 处）

### 4.2 改 API 地址

如果后台换了域名，全局搜索替换 `admin.pastorjeffnchina.com` 为新域名。

### 4.3 改产品展示的颜色映射

编辑 `src/components/ProductShowcase.astro`，搜索 `const colorMap`：
```javascript
const colorMap = { '白色': '#f0f0f0', '黑色': '#222', ... }
```
添加新颜色就加一对 `'颜色名': '#色值'`。

### 4.4 改网站标题/Logo

编辑以下文件的 `title` 属性：
- `src/pages/en/index.astro` → BaseLayout 的 `title="..."`
- `src/pages/zh/index.astro` → 同上

Logo 在 `src/layouts/BaseLayout.astro` 里改。

<script is:inline>

## 七、注意事项

1. **产品图片**：后台产品管理上传的图片存在 `products/admin/static/uploads/`，前台通过 Cloudflare Tunnel 访问
2. **缓存**：Cloudflare Pages 有 CDN 缓存，部署后可能需要 1-2 分钟才能看到更新
3. **SEO**：因为是客户端 JS 渲染，搜索引擎抓取时可能看不到内容。后续可改为服务端渲染改善
4. **数据格式**：API 返回的 `colors`、`sizes`、`images` 字段是 JSON 字符串，前端用 `JSON.parse()` 解析
