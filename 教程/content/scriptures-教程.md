# scriptures.json 教程 —— 经文卡片列表

## 📍 文件位置
`src/content/scriptures.json`

## 🎯 用途
被 **Scripture3D.astro** 读取，用于展示：
- 一个经文卡片轮播/列表，每条包含中英文经文正文和出处

## 📋 字段说明

| 字段路径 | 类型 | 示例值 | 说明 |
|---------|------|--------|------|
| `[].zh` | string | `"「我岂没有吩咐你吗？...」"` | 中文经文内容（含中文引号） |
| `[].refZh` | string | `"约书亚记 1:9"` | 中文出处/章节 |
| `[].en` | string | `"\"Have I not commanded you?...\""` | 英文经文内容（含英文双引号） |
| `[].refEn` | string | `"Joshua 1:9"` | 英文出处/章节 |

数据结构：一个 **JSON 数组**，每个元素是一个对象，含 4 个字段。

## ✏️ 修改指南

### 🟢 安全修改
- **改某条经文** → 找到对应数组元素的 `zh` / `en` 字段
- **改出处** → 对应 `refZh` / `refEn`
- **增删经文** → 增/删整个数组对象，注意保持四条字段都在

### 🔴 不能改 / 改了会崩
- **必须是数组** — 顶层 `[...]` 不能改成 `{...}`
- **每个元素必须 4 个字段齐全** — `zh`, `refZh`, `en`, `refEn` 缺一不可
- **中文经文用全角引号 `「」`** — 不要误用 `""`（半角）
- **英文经文用半角双引号** — 在 JSON 中必须转义为 `\"`
- **数组元素之间加逗号** — 最后一个不加逗号（JSON 规范）
- **不要改字段名** — `zh` 不能改名，Scripture3D.astro 硬编码了这些字段名

## 📦 被哪些组件读取
- **Scripture3D.astro**：遍历数组，渲染 3D 经文卡片
