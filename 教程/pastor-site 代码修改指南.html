第一章 · 项目概览

技术栈

Astro 5 + Tailwind CSS 3 + Cloudflare Pages

项目位置：~/Desktop/pastor-site/

常用命令

npm run dev      # 本地开发服务器（localhost:4321）
npm run build    # 构建生产版本
npm run preview  # 预览构建结果

部署方式

GitHub 仓库 → Cloudflare Pages 自动部署（push main 分支即触发）

第三章 · 修改指南

3.1 修改网站文字内容

网站名

文件：src/content/site.json → site.name.zh / site.name.en

牧师介绍 + 经文

文件：src/content/hero.json → en.name / zh.name / .title / .preview / .verse

经文轮播

文件：src/content/scriptures.json → 数组中每项的 .en / .zh

异象内容

文件：src/content/vision.json → .zh.content / .en.content

3.2 修改联系信息

WhatsApp 号 / 邮箱

文件：src/content/site.json → site.whatsapp / site.email

3.3 修改产品/商品

数据 → src/content/products.json（含价格、颜色、尺码、图片路径）

图片 → public/images/products/ 目录

3.4 修改样式/品牌色

主色调 → tailwind.config.mjs：beige（浅米背景）、charcoal（深灰文字）、sage（鼠尾草绿 CTA）

按钮 → src/styles/global.css：.btn-primary / .btn-outline

3.5 修改导航/布局

导航栏 + 页脚 + 购物车浮窗 → 全部在 src/layouts/BaseLayout.astro

3.6 新增语言

  1. astro.config.mjs → i18n.locales 加新语言代码
  2. src/content/ 所有 JSON 加新语言键
  3. src/pages/[新语言]/ 创建页面目录
  4. 重新构建

第五章 · 注意事项

JSON 文件不支持注释，教程写在配套的 -教程.md 文件中
.astro 文件的 JSX 表达式内不能用 <!-- --> 注释，会编译报错
修改 Astro 文件后需 npm run build 重新构建才能上线
管理后台是独立项目（~/Desktop/products/admin/），不在 pastor-site 目录内
敏感信息（API Key、密码）走环境变量，不写代码文件
